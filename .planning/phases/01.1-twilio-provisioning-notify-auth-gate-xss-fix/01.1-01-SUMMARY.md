# Phase 01.1 Plan 01: Auth Gate + XSS Helpers + Type Cleanup Summary

**One-liner:** requireAuth() and escapeHtml() helpers created, all 4 diagnostic routes auth-gated, dashboard sends Authorization header, NotificationResponse renamed to whatsappDmStatus with client-side lastNotifiedAt replaced by server-side dedup Map.

## What Was Built

### lib/require-auth.ts
Exports `requireAuth(request: NextRequest): NextResponse | null`. Extracts Bearer token from Authorization header, decodes Base64, compares against `DASHBOARD_PASSWORD`. Returns 401 on failure, null on success. Try-catch wraps decode to prevent crashes on malformed tokens.

### lib/escape-html.ts
Exports `escapeHtml(s: string): string`. Replaces `& < > " '` with HTML entities in the standard order. Applied to `member.name` in both HTML email variants (first-notify and resend) in `app/api/notify/route.ts`.

### types/index.ts changes
- `NotificationRequest.lastNotifiedAt` removed — server is now the authority on dedup timing
- `NotificationResponse.results[].whatsappStatus` renamed to `whatsappDmStatus` — removes the SMS-overloaded field name from Phase 01
- Added comment: "Server enforces 60s dedup cooldown per groupNumber — no client-supplied timestamp needed"

### 4 diagnostic routes auth-gated
All 4 routes (`whatsapp-status`, `whatsapp-groups`, `test-notify`, `test-whatsapp-cloud`) now call `requireAuth(request)` as the very first operation. Handler signature changed from `GET()` to `GET(request: NextRequest)`.

### app/page.tsx
- `handleNotify`: removed `lastNotifiedAt` from request body, added `Authorization: Bearer ${localStorage.getItem('wedding_auth')}` header
- `handleBulkNotify`: same changes applied

### app/api/notify/route.ts (auto-fix deviations)
Type changes in `types/index.ts` required fixing `notify/route.ts` to compile cleanly:
- Replaced client-side `body.lastNotifiedAt` dedup check with server-side `lastSentMap` (module-level `Map<number, number>`)
- `isResend` now derived from `lastSentMap.get(groupNumber) !== undefined`
- `whatsappStatus` renamed to `whatsappDmStatus` in all results pushes and anySuccess checks
- Applied `escapeHtml()` to `member.name` in HTML email body templates (XSS fix CR-01)
- `lastSentMap.set(groupNumber, Date.now())` called after successful dispatch to record send time
