  <action>
1. Create `lib/require-auth.ts`:
   - Export `requireAuth(request: NextRequest): NextResponse | null`
   - Extract token from `Authorization` header: `request.headers.get('Authorization')?.replace('Bearer ', '')`
   - If no token, return `NextResponse.json({ success: false, message: 'Unauthorized' }, { status: 401 })`
   - Decode with `Buffer.from(token, 'base64').toString()`, split on ':', compare first part to `process.env.DASHBOARD_PASSWORD`
   - If mismatch, return 401 response
   - If valid, return `null` (meaning "proceed")
   - Wrap in try-catch — any decode error returns 401

2. Create `lib/escape-html.ts`:
   - Export `escapeHtml(s: string): string`
   - Replace in order: `&` -> `&amp;`, `<` -> `&lt;`, `>` -> `&gt;`, `"` -> `&quot;`, `'` -> `&#39;`
   - This is the standard 5-character HTML entity escape

3. Update `types/index.ts`:
   - In `NotificationResponse.results`, rename `whatsappStatus` to `whatsappDmStatus` (this field will track per-member WhatsApp DM status after Twilio removal in Plan 02)
   - Remove the comment "SMS status via Twilio" and replace with "WhatsApp DM status: 'sent' | 'failed' | 'skipped' | 'simulated-success'"
   - In `NotificationRequest`, remove the `lastNotifiedAt` field entirely (server-side dedup in Plan 02 replaces it)
   - Add a comment on `NotificationRequest` noting: "Server enforces 60s dedup cooldown per groupNumber — no client-supplied timestamp needed"
