  <action>
Rewrite `app/api/notify/route.ts` with these changes (in order of appearance in the file):

**Imports:**
- Remove: `import twilio from 'twilio';`
- Remove: `import { getWhatsAppClient, getWhatsAppStatus } from '@/lib/whatsapp-session';`
- Add: `import { requireAuth } from '@/lib/require-auth';`
- Add: `import { escapeHtml } from '@/lib/escape-html';`
- Add: `import { whenReady } from '@/lib/whatsapp-session';`
- Keep: `import { NextRequest, NextResponse } from 'next/server';`
- Keep: `import nodemailer from 'nodemailer';`
- Keep: `import type { NotificationRequest, NotificationResponse } from '@/types';`

**Server-side dedup Map (module level, above the POST handler):**
```typescript
// Server-side dedup: Map<groupNumber, lastSendTimestamp>
// Safe on Hetzner VPS — long-running process, Map persists across requests
const lastSendMap = new Map<number, number>();
const COOLDOWN_MS = 60_000;
```

**POST handler — top of function:**
1. Auth gate (FIRST thing): `const authError = requireAuth(request); if (authError) return authError;`
2. Parse body: `const body: NotificationRequest = await request.json();`
3. Extract `groupNumber` and `members` from body.
4. Server-side dedup check:
   ```typescript
   const lastSend = lastSendMap.get(groupNumber);
   if (lastSend && Date.now() - lastSend < COOLDOWN_MS) {
     const waitSec = Math.ceil((COOLDOWN_MS - (Date.now() - lastSend)) / 1000);
     return NextResponse.json(
       { success: false, message: `Notification sent too recently. Wait ${waitSec} seconds before resending.` },
       { status: 429 }
     );
   }
   ```
5. Remove all references to `body.lastNotifiedAt` — the server Map is the authority now.

**Remove ALL Twilio/SMS code:**
- Delete `twilioClient` initialization block (lines ~35-38 in current file)
- Delete `messageText` function (used for SMS body only — WhatsApp DMs have their own inline message)
- In the production (non-test) per-member loop: delete the entire "Send SMS via Twilio" block (lines ~122-134)
- Delete `smsStatus` variable and all references
- In test mode loop: remove the SMS simulation log line

**Apply escapeHtml to HTML email bodies:**
- In the HTML email template (both first-notify and resend variants), wrap every `${member.name}` interpolation with `${escapeHtml(member.name)}`
- There are 2 HTML templates (resend and first-notify), each with one `${member.name}` interpolation in a `<p>` tag
- Plaintext email body does NOT need escaping (keep `${member.name}` as-is in text versions)

**Update per-member results to use new field name:**
- Change `whatsappStatus: smsStatus` to `whatsappDmStatus: 'skipped'` in the results push (SMS is gone; WhatsApp DM status will be updated below)
- In test mode results: change `whatsappStatus: 'simulated-success'` to `whatsappDmStatus: 'simulated-success'`

**WhatsApp Group Post — use whenReady():**
Replace the current pattern:
```typescript
const { status } = getWhatsAppStatus();
if (status !== 'ready') { ... }
const client = getWhatsAppClient();
```
With:
```typescript
try {
  const client = await whenReady();
  await client.sendMessage(whatsappGroupId, whatsappGroupMessage);
  response.whatsappGroupStatus = 'sent';
} catch (whatsappError) {
  console.error('[WhatsApp] Group post error:', whatsappError);
  response.whatsappGroupStatus = 'failed';
}
```
Keep the `whatsappGroupId` check before this block (skip if not set).

**WhatsApp Individual DMs — use whenReady():**
Replace the current `getWhatsAppStatus()` + `getWhatsAppClient()` pattern with:
```typescript
try {
  const client = await whenReady();
  for (const member of members) {
    // ... existing phone cleanup and chatId logic ...
    try {
      await client.sendMessage(chatId, dmMessage);
      console.log(`[WhatsApp DM] Sent to ${member.name} (${chatId})`);
      // Update the member's result entry whatsappDmStatus to 'sent'
      const memberResult = response.results!.find(r => r.member === member.name);
      if (memberResult) memberResult.whatsappDmStatus = 'sent';
    } catch (dmError) {
      console.error(`[WhatsApp DM] Error for ${member.name} (${chatId}):`, dmError);
      const memberResult = response.results!.find(r => r.member === member.name);
      if (memberResult) memberResult.whatsappDmStatus = 'failed';
    }
  }
} catch {
  console.warn('[WhatsApp DM] Client not ready — skipping individual messages');
}
```

**Update anySuccess check:**
Remove all SMS-related status checks. It should be:
```typescript
const anySuccess = response.results!.some(
  (r) => r.emailStatus === 'sent' || r.emailStatus === 'simulated-success' ||
         r.whatsappDmStatus === 'sent' || r.whatsappDmStatus === 'simulated-success'
);
```

**Update response message:**
Remove SMS count from the summary message. Change to:
```typescript
const emailCount = response.results!.filter(r => r.emailStatus === 'sent' || r.emailStatus === 'simulated-success').length;
const dmCount = response.results!.filter(r => r.whatsappDmStatus === 'sent' || r.whatsappDmStatus === 'simulated-success').length;
response.message = `Sent to ${members.length} member(s): ${emailCount} emails, ${dmCount} WhatsApp DMs`;
```

**Record successful send in dedup Map (after anySuccess check):**
```typescript
if (anySuccess) {
  lastSendMap.set(groupNumber, Date.now());
}
```
This ensures the cooldown only activates after a successful send, not after failures.

**isResend determination:**
Since `lastNotifiedAt` is gone from the request, determine isResend by checking the server-side Map:
```typescript
const isResend = lastSendMap.has(groupNumber);
```

Place this BEFORE the cooldown check (so the cooldown check can reject, but isResend is still set for message variant selection). Actually, rethink: the Map records successful sends. If a group was sent before (Map has entry) but cooldown has passed, `isResend` should be `true`. This correctly determines first-notify vs resend message variants.
